# Saltwater General Store — V0.5.1

## New
- Interactive first-order tutorial.
- First customer is deliberately a simple 1 × chips order.
- Tutorial pauses normal customer spawning while the player learns.
- Step 1: swipe down customer to take order.
- Step 2: tap Chips once to load.
- Step 3: swipe down Chips to cook.
- Step 4: wait for READY.
- Step 5: swipe up to send.
- Automatic docket completion, bell and reward are demonstrated before normal play begins.
- Each step only advances after the correct interaction.
- Current target is spotlighted so the player knows where to touch.
- SOUND ON / SOUND OFF button added to the main menu.
- Sound toggle controls both game audio and vibration feedback for this prototype.

All V0.5 art, 100-NPC system, patience bars, upgrades and gameplay are retained.
